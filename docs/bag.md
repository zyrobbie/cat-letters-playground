# 纸袋躲猫猫

有猫来信的独立静态互动试片。不连接主线账号、来信或存储，不影响猫的状态或旅行。

## 本地运行

在 `public` 目录启动任意静态 HTTP 服务。无需构建或运行时依赖。通过 HTTPS 或 localhost 打开，不建议 file URL。

## 验证

`npm test` 使用 Node 内置测试运行器；`node --check public/game.mjs` 检查 UI 脚本语法。

页面支持鼠标、触屏指针以及点击/键盘替代。旅行模式不显示猫，只寻找留在家里的小玩具。每段完成后用户手动继续，第三段自然结束，可随时回家。

## 发布

将 `public` 内文件发布到独立站点的 `bag/` 路径，保留子目录和相对路径。不要覆盖另一个游戏或主产品。所有图像为本项目批准素材及其衍生；不包含用户对话、凭据、账号或外部跟踪。
