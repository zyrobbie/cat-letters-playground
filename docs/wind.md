# 窗边一阵风

「有猫来信」独立轻互动试片，发布于 `/wind/`。所有页面和资源相对引用，不接主产品、账号、来信或后端。

## 玩法

在同一个家的右窗地板上，慢慢划动带起风，轻点纸叶或使用三个吹风按钮也可以。三种纸叶的重量不同；浅盘里摩擦更大，纸叶更容易停下来。没有必须收齐的目标。狸花猫偶尔按住一片，再轻轻拨开。用户随时可以保留当前摆法、回家或再玩；旅行场景完全移除猫及其碰撞。

## 本地验证

`npm test` 执行纯 Node 物理测试，无依赖安装。`node --check public/game.mjs` 检查界面模块语法。

需要通过普通 HTTP 服务器访问 `public/`，不支持 file:// ES modules。正式候选的云端 Chromium 操作检查由独立 QA 执行。纯模型测试不等于手机或浏览器验收。

## 设计与数据边界

家庭空间与狸花姿态复用主产品已定资源，沿用纸箱滚球已通过的排版、字体、暖纸配色。纸叶和极浅盘为同画风新独立素材。没有积分、签到、自动关卡、货币或心理效果承诺。图片预加载失败提供重载入口；离开页面或失焦时暂停，回来不补算离开时间。
