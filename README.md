# 有猫来信 · 纸箱滚球

独立静态轻互动试片，不连接主产品账号、数据库或来信，不修改主产品。

## 本地运行

Node 22+ 用于测试；运行 `npm test` 和 `npm run check`。
`npm run serve` 后访问 http://localhost:8091 。发布目录仅 `public/`。

## 体验

在熟悉的家庭场景中选择「玩一会儿」。拖动纸板、轻点纸板转向，然后「轻推一下」。也可用明确的左转/右转、选择纸板、微调按钮或键盘控制。球的轨迹由真实碰撞反射决定，不是预设成功动画。封闭纸箱是固定实心障碍物，不可拖动；可移动的只有纸板。球会绕开或撞上纸箱后弹开，不能穿箱。球、猫、纸箱及每块纸板按地面位置排列前后遮挡，猫的地面身体范围也有碰撞。只在前爪附近且收尾路径无遮挡时接球。

共三种简短摆法，继续与结束由用户选择。没有积分、签到、道具货币、失败惩罚、自动续局或主线收益。「测试场景」可切换在家与旅行，旅行状态没有实时小猫。

在浏览器后台或窗口失焦时不推进滚球时间；重新聚焦不会补算离开期间的时间。前台低帧率仍按真实经过时间分步积分，不改变球速；返回首页、切换场景、重新开始均取消旧动画。降低动态效果偏好关闭额外爪部动作与碰撞提示，保留玩法所需的球运动。

## 素材来源

房间与狸花猫基于 `zyrobbie/travel-cat-planner` 中既有产品视觉资产。游戏场景局部去除背景的原静态球，以免与交互球重影；保留家庭家具与布局。玩球与伸懒腰姿势复用原有透明角色图。纸板、封闭纸箱与黄色条纹球沿用此视觉体系新增。

只有本试片所需的代码和展示资产被发布；不携带主产品源码、会话、配置、账号数据或密钥。
